    Installation

    CityLearn v3 is distributed as citylearn on PyPI and requires Python 3.10 or newer. The core installation runs every simulation that needs neither LSTM thermal dynamics nor the bundled reinforcement learning controllers, and takes about 200 MB with its dependencies.

    Use a virtual environment to keep its dependencies separate.

    python -m venv .venv

    Activate it on Linux or macOS:

    source .venv/bin/activate

    On Windows PowerShell:

    .venv\Scripts\Activate.ps1

    Install and check the package:

    python -m pip install --upgrade pip
python -m pip install citylearn
python -c "from citylearn import __version__; print(__version__)"

    Continue with Your first simulation. Both the package and Python import name are citylearn.

    Optional dependencies

    Extras add the dependencies of features that not every study needs. Install several at once by separating them with commas, for example "citylearn[rl,parquet]".

    python -m pip install "citylearn[rl]"

    The default PyTorch wheels for Linux include the CUDA libraries, about 5 GB in all. Without a GPU, install the CPU-only PyTorch first, then the extra, which then keeps that PyTorch:

    python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install "citylearn[rl]"

    A dataset or controller that needs a missing extra raises an ImportError that names the command to install it. Stable Baselines3 and RLlib are not extras: install Stable Baselines3 2.4 or newer to use StableBaselines3Wrapper (see Train and evaluate a reinforcement learning controller), and ray[rllib] to use the RLlib wrappers (see Train a controller with RLlib). The RLlib wrappers are tested with Ray 2.60.0 (requiring a checkout of master or a release newer than 3.6.0), which supports Python 3.10 to 3.14 and pins gymnasium 1.2.2; other Ray releases pin other gymnasium versions.

    Datasets, cache and offline use

    Public datasets are downloaded from the official repository on first use and cached locally, so the first download needs internet access. List the available names in Python, or with citylearn list_datasets:

    from citylearn.data import DataSet
print(DataSet().get_dataset_names())

    The cache is a citylearn folder in the user cache directory, with one subfolder per dataset release, for example ~/.cache/citylearn/v3.6.0 on Linux; DataSet().cache_directory returns it and DataSet().clear_cache() empties it. Downloads go to its datasets folder. A complete local copy of a dataset, such as data/datasets in a repository checkout, is copied to datasets_by_content/<key>/<dataset>, where the key is a digest of its files, so checkouts with different data never share a copy. For your own data, pass a local schema.json path instead of a dataset name. See Dataset Reference for files and units.

    These environment variables change where CityLearn looks for data:

    Variable

    Effect

    CITYLEARN_OFFLINE

    1 makes offline mode the default: nothing is downloaded, and data must be in the cache or in a local root.

    CITYLEARN_LOCAL_DATASETS_PATH

    Folders (separated by :, or ; on Windows) searched for dataset folders before downloading; each dataset folder holds its schema.json.

    CITYLEARN_LOCAL_MISC_PATH

    Folders searched for the shared files (such as sizing data) before downloading.

    CITYLEARN_DATASET_GITHUB_ACCOUNT, CITYLEARN_DATASET_REPOSITORY, CITYLEARN_DATASET_TAG

    Repository and tag that datasets are downloaded from; the tag also names the cache subfolder.

    CITYLEARN_GITHUB_TOKEN (or GITHUB_TOKEN)

    GitHub token that raises the anonymous limit of 60 API requests per hour.

    To work offline, run once online so that the cache holds the datasets you need, or point CITYLEARN_LOCAL_DATASETS_PATH at a folder of dataset folders, then set CITYLEARN_OFFLINE=1 or pass offline=True to CityLearnEnv.

    Existing projects and development

    Record the installed version with the command above and pin that version in your project dependencies. Read Moving an existing project to CityLearn v3 when updating a project. To work on CityLearn itself, follow Developer Guide.

    Reproducibility and older releases

    CityLearn supports NumPy 1.x and 2.x: observations, rewards and simulated time series are bit-identical on both. KPIs can differ in the last binary digits (relative differences of order 1e-15), for two reasons. NumPy 2.3 and later add up more than 8,192 values in a different order, which affects totals over episodes longer than 8,192 time steps, such as a full year of hourly steps, and the district Gini ratio of more than 90 members. The equity audit’s Gini ratio uses a BLAS dot product, whose last digit depends on the BLAS build and the CPU, and NumPy 1 and 2 wheels ship different OpenBLAS releases.

    Troubleshooting installation

    No matching distribution found for openstudio<=3.3.0

    CityLearn 2.2.0 to 2.5.0 required OpenStudio 3.3.0 or older, which PyPI does not provide for recent Python versions (reported for 3.10 and 3.11). Install CityLearn 3.2.0 or newer: OpenStudio and doe_xstock are then needed only for citylearn.end_use_load_profiles and come with the end_use_load_profiles extra.

    scikit-learn fails to compile, for example with an OpenMP error on macOS

    CityLearn 2.2.0 to 3.2.0 pinned scikit-learn<=1.2.2, which has no wheels for Python 3.12 or newer, so pip tries to build it from source. Install CityLearn 3.3.0 or newer, or use Python 3.11 or older for those releases.

    TypeError: 'staticmethod' object is not callable when importing CityLearn

    Reported for CityLearn 2.3.0 on Python 3.9. Install a current release.

    ImportError naming citylearn[dynamics] or citylearn[rl]

    Since the release after 3.6.0, PyTorch and scikit-learn are optional. Install the extra that the message names; see Optional dependencies.

    An old release is required to reproduce earlier results

    Install it without dependencies and then the dependencies that the table above lists for it, with versions available for your Python:

    python -m pip install --no-deps citylearn==2.3.1
