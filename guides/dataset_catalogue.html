This documentation is built from the development branch, master. It includes the changes listed under Unreleased, which the latest release, CityLearn 3.6.0, does not have. To read the documentation of the version you installed (pip show citylearn), open the docs folder at its tag on GitHub, for example v3.6.0.

Dataset catalogue

This table is generated from the bundled schemas when the documentation is built. Pass a name to CityLearnEnv to download and cache the dataset on first use; the size is the download. Default window is the schema’s simulation window, which simulation_start_time_step, simulation_end_time_step and episode_time_steps can shorten. Parquet datasets need pip install "citylearn[parquet]", and datasets with LSTM thermal dynamics need PyTorch; see the installation guide.

Where to start

  • First runs and controller comparisons: citylearn_challenge_2022_phase_all_plus_evs, used by the quickstart.

  • Electrical limits, dynamic topology and sub-minute data: the citylearn_three_phase_* demonstrations; see the features guide.

  • Renewable energy communities with a local market: pt_rec_4 first, then pt_rec_15, pt_rec_30 and pt_rec_100.

  • Demand response and robustness: citylearn_challenge_2022_phase_all_demand_response and citylearn_challenge_2022_phase_all_robustness.
