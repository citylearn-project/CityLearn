citylearn.internal.grid_availability module

Time-varying grid import availability for a building’s electrical service.

A building’s electrical_service may reference a per-time-step series of the grid power that the building may import, in [kW]. It models curtailment of the grid connection below its static capacity, for example a distribution system operator dimming controllable devices (the German §14a EnWG scheme) or a temporary capacity reduction during grid stress.

The import limit in force at a time step is the smaller of the static electrical_service.limits.total.import_kw and the series value. A missing (NaN) series value falls back to the static limit. The limit acts through the existing electrical-service allocation: EV chargers and the electrical storage are curtailed first, and load that cannot be curtailed stays served and is recorded as a service violation. It does not island the building; model a blackout with power_outage instead.

Columns of an available grid power file; one row per dataset time step.

Every column is kept, so buildings that share one file (one column per building) also share one loaded copy. Column values are read through column() and follow the episode window like any other time series.
