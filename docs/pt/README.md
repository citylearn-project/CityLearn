# Documentação em português

Guias de utilização, configuração e desenvolvimento. A versão inglesa encontra-se
em `docs/*.md`; os identificadores de campos, classes e KPIs mantêm o nome da API.

A versão inglesa é a referência. Cada guia inglês tem uma tradução aqui, com as
mesmas secções, factos e exemplos de código. As notas de versão são atualizadas
com cada alteração e podem agrupar as entradas de outra forma. Em caso de
diferença, prevalece a versão inglesa.
