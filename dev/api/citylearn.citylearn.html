    class citylearn.citylearn.CityLearnEnv(schema: str | Path | Mapping[str, Any], root_directory: str | Path = None, buildings: List[Building] | List[str] | List[int] = None, electric_vehicles: List[ElectricVehicle] | List[str] | List[int] = None, simulation_start_time_step: int = None, simulation_end_time_step: int = None, episode_time_steps: int | List[Tuple[int, int]] = None, rolling_episode_split: bool = None, random_episode_split: bool = None, seconds_per_time_step: float = None, reward_function: RewardFunction | str = None, reward_function_kwargs: Mapping[str, Any] = None, central_agent: bool = None, shared_observations: List[str] = None, active_observations: List[str] | List[List[str]] = None, inactive_observations: List[str] | List[List[str]] = None, active_actions: List[str] | List[List[str]] = None, inactive_actions: List[str] | List[List[str]] = None, simulate_power_outage: bool = None, solar_generation: bool = None, random_seed: int = None, offline: bool = None, time_step_ratio: int = None, interface: str = None, topology_mode: str = None, start_date: str | date = None, render_session_name: str = None, render_mode: str = 'none', export_kpis_on_episode_end: bool = None, **kwargs: Any)[source]

    Bases: Environment, Env

    CityLearn environment: a Gymnasium environment that simulates a community of buildings.

    Each step applies the controller’s actions to the buildings’ storage, EV chargers and flexible loads for one control interval and returns the next observations and rewards. After an episode, evaluate_v2() returns the KPI table and scorecard() its default selection.

    Parameters:

    • schema (Union[str, Path, Mapping[str, Any]]) – Name of CityLearn data set, filepath to JSON representation or dict object of a CityLearn schema. Call citylearn.data.DataSet.get_dataset_names() for the list of public CityLearn data sets.

    • root_directory (Union[str, Path]) – Absolute path to directory that contains the data files including the schema.

    • buildings (Union[List[Building], List[str], List[int]], optional) – Buildings to include in environment. If list of citylearn.building.Building is provided, will override buildings definition in schema. If list of :str: is provided will include only schema buildings keys that are contained in provided list of str. If list of :int: is provided will include only schema buildings whose index is contained in provided list of int.

    • electric_vehicles (Union[List[ElectricVehicle], List[str], List[int]], optional) – Electric vehicles to include, selected from the schema’s electric_vehicles_def in the same way as buildings: instances, names or indices. Defaults to every EV in the schema.

    • simulation_start_time_step (int, optional) – Time step to start reading data files contents.

    • simulation_end_time_step (int, optional) – Time step to end reading from data files contents.

    • episode_time_steps (Union[int, List[Tuple[int, int]]], optional) – If type is int, it is the number of time steps in an episode. If type is List[Tuple[int, int]]] is provided, it is a list of episode start and end time steps between simulation_start_time_step and simulation_end_time_step. Defaults to (simulation_end_time_step - simulation_start_time_step) + 1. An episode of N time steps (states) executes N - 1 control steps. rolling_episode_split is ignored when episode_time_steps is a list. A list outside the simulation window raises ValueError. When simulation_start_time_step or simulation_end_time_step narrows the window and this argument is not given, the schema’s list is clipped to the window and its episodes without an interval inside the window are dropped.

    • rolling_episode_split (bool, default: False) – True if episode sequences are split such that each time step is a candidate for episode_start_time_step otherwise, False to split episodes in steps of episode_time_steps.

    • random_episode_split (bool, default: False) – True if episode splits are to be selected at random during training otherwise, False to select sequentially.

    • time_step_ratio_mode (str, default: 'reject') – What to do when seconds_per_time_step differs from the dataset step, i.e. time_step_ratio != 1. CityLearn does not resample the data: each control step reads one data row. ‘reject’ raises a ValueError, so that a run never simulates distorted time. ‘compress’ keeps the CityLearn 3.6.0 behaviour: each control step still reads one row, so the calendar, prices and EV schedules advance one row per step, while energies are scaled by the ratio. Can also be set with the schema key of the same name.

    • episode_split_boundary (str, default: 'shared') – How consecutive (non-rolling) splits of an integer episode_time_steps meet. An episode of N data rows executes N - 1 control steps, because its last row is only the terminal observation. ‘shared’ advances consecutive episodes by N - 1 rows, so the terminal row of one episode is the first row of the next and every interval is simulated (N must be at least 2). ‘disjoint’ advances them by N rows, as CityLearn 3.6.0 and earlier did, so the interval between two consecutive episodes is never simulated. Can also be set with the schema key of the same name. Rolling and explicit list splits are not affected.

    • ev_soc_carryover (bool, default: False) – Start each EV of an episode from its SOC at the end of the previous episode, when the new episode continues it in time: it starts on the previous episode’s last row (‘shared’) or on the row after it (‘disjoint’), and the previous episode ran to its end. Sequential splits carry, and an explicit list of episode_time_steps carries when a window starts exactly there. Random and rolling splits never carry, even when a pick happens to follow the previous episode, and the env warns once that the setting has no effect. Only the session connected across the boundary keeps its charge, at the new episode’s first step; every later arrival takes the schedule SOC, and an arrival without one keeps the EV’s simulated SOC, as in one run. The first episode uses the schedule SOC, as when the setting is off. Only the EV SOC is carried: batteries, thermal storage and indoor temperatures still start every episode from their initial state. Off, episodes are independent; on, an episode that continues the previous one depends on what the previous controller did. Can also be set with the schema key of the same name.

    • seconds_per_time_step (float) – Number of seconds in 1 time_step and must be set to >= 1. It must equal the dataset step unless time_step_ratio_mode=’compress’.

    • time_step_ratio (int, optional) – Ratio of the control step to the dataset step. It is inferred from the data; a value passed here must match the inferred ratio, otherwise a ValueError is raised.

    • reward_function (Union[RewardFunction, str], optional) – Reward function class instance or path to function class e.g. ‘citylearn.reward_function.IndependentSACReward’. If provided, will override reward_function definition in schema.

    • reward_function_kwargs (Mapping[str, Any], optional) – Parameters to be parsed to reward_function at intialization.

    • central_agent (bool, optional) – Expect 1 central agent to control all buildings.

    • shared_observations (List[str], optional) – Names of common observations across all buildings i.e. observations that have the same value irrespective of the building.

    • active_observations (Union[List[str], List[List[str]]], optional) – List of observations to be made available in the buildings. Can be specified for all buildings in a List[str] or for each building independently in a List[List[str]]. Will override the observations defined in the schema.

    • inactive_observations (Union[List[str], List[List[str]]], optional) – List of observations to be made unavailable in the buildings. Can be specified for all buildings in a List[str] or for each building independently in a List[List[str]]. Will override the observations defined in the schema.

    • active_actions (Union[List[str], List[List[str]]], optional) – List of actions to be made available in the buildings. Can be specified for all buildings in a List[str] or for each building independently in a List[List[str]]. Will override the actions defined in the schema.

    • inactive_actions (Union[List[str], List[List[str]]], optional) – List of actions to be made unavailable in the buildings. Can be specified for all buildings in a List[str] or for each building independently in a List[List[str]]. Will override the actions defined in the schema.

    • simulate_power_outage (Union[bool, List[bool]]) – Whether to simulate power outages. Can be specified for all buildings as single bool or for each building independently in a List[bool]. Will override power outage defined in the schema.

    • solar_generation (Union[bool, List[bool]]) – Wehther to allow solar generation. Can be specified for all buildings as single bool or for each building independently in a List[bool]. Will override pv defined in the schema.

    • random_seed (int, optional) – Pseudorandom number generator seed for repeatable results.

    • random_stream_version (str, optional) – Keyword argument. How the random streams for unspecified device parameters, away-from-charger EV state of charge, occupant set-point interactions and stochastic power outages are derived from random_seed: 'v2' (default) derives one independent stream per purpose, object and episode with numpy.random.SeedSequence; 'v1' reproduces CityLearn 3.6.0 and earlier. Overrides random_stream_version in the schema. Agents built on the environment use the same version for their own random streams. See citylearn.random_streams.

    • offline (bool, optional) – If True, disables all network fallbacks for datasets and misc sizing data. Initialization fails with a clear error when required files are not available locally. Defaults to the CITYLEARN_OFFLINE environment variable, read at initialization, or False when it is unset.

    • interface (str, optional) – Observation and action contract: 'flat' (default) returns one vector per agent; 'entity' returns tables of buildings, chargers, EVs and other assets with their edges. Overrides the schema key. See the flat and entity interfaces guide.

    • topology_mode (str, optional) – 'static' (default) keeps the members and assets of the schema for the whole episode; 'dynamic' applies the schema’s topology_events (members and assets joining or leaving) and requires interface='entity'. Overrides the schema key.

    • start_date (Union[str, datetime.date], optional) – Date of the first time step in rendered and exported timestamps, e.g. '2024-01-01'. Defaults to the schema’s start_date, else 2024-01-01. It does not change the simulation.

    • render_directory (Union[str, Path], optional) – Base directory where rendering and export artifacts are stored. Relative paths are resolved from the current working directory.

    • render_directory_name (str, optional) – Folder name created in the current working directory for rendering and export artifacts when render_directory is not provided. Defaults to render_logs.

    • render_session_name (str, optional) – Name of the subfolder created under render_directory/render_directory_name for export artifacts. When omitted, a timestamp is used.

    • render (bool, optional) – Legacy render switch. Prefer render_mode.

    • render_file_format (str, optional) – Format of rendered and exported series: 'csv' (default) or 'parquet', which needs pyarrow.

    • render_chunk_size (int, optional) – Number of rows buffered before a rendered file is written. Defaults to 100,000 for CSV and 50,000 for Parquet.

    • render_mode (str, optional) – Rendering strategy. Accepted values are 'none' (default), 'during' for streaming exports each step, and 'end' for exports performed at episode completion while still allowing manual snapshots via render().

    • export_kpis_on_episode_end (bool, optional) – Whether to automatically export exported_kpis.csv when an episode terminates. If not provided, defaults to the effective rendering setting (enabled when rendering is enabled).

    • export_only_final_episode (bool, optional) – Whether automatic exports should run only on the final planned episode. Defaults to True.

    • ev_departure_within_tolerance (float, optional) – Symmetric SOC target accuracy tolerance used by EV departure within-tolerance KPIs. Defaults to 0.05.

    • ev_departure_service_tolerance (float, optional) – Lower SOC service tolerance used by EV departure minimum-acceptable KPIs. Defaults to 0.05.

    • business_as_usual_ev_charge_target (str, optional) – EV charging of the native BAU reference built by evaluate_v2(): 'full' charges to 100%, 'requested' to the user’s requested departure SOC. Defaults to the schema value, else 'full'.

    • physics_version (int, optional) – Physics definitions: 2 (default) or 1, which reproduces the physics of CityLearn 3.6.0. Overrides the schema key. The migration guide lists the corrections of version 2.

    • baseline_version (int, optional) – Definition of the default KPI baseline (the *_without_storage series) and of the native BAU HVAC: 2 (default) removes the battery, the thermal storage and the EV charging of the controlled run, and adds back the EV charging of the native BAU with the 'full' target, so it is the same for every controller and has no V2G; its native BAU also runs the HVAC so that it delivers the dataset’s own heating and cooling demand. 1 adds nothing back and its BAU sends zero to the HVAC actions, as in CityLearn 3.6.0. Overrides the schema key. See citylearn.internal.baseline_version.

    • debug_timing (bool, optional) – Log runtime timings. Defaults to the schema value, else False.

    • check_observation_limits (bool, optional) – Check observations against their estimated bounds. Defaults to the schema value, else False.

    • physics_invariant_checks (bool, optional) – Check physical invariants at runtime. Defaults to the schema value, else False.

    • metrics_log_interval (int, optional) – Log runtime metrics every this many steps; 0 (default) disables them.

    • energy_provenance (bool, optional) – Whether to keep the per-step electricity provenance ledger (*_energy_provenance_* KPIs and provenance audits). Defaults to True. Disabling it does not change any simulated quantity and makes step() substantially faster, e.g. for training runs that do not report provenance KPIs.

    • district_electrical_service (Mapping[str, Any], optional) – Opt-in shared feeder monitoring configuration, e.g. {"enabled": True, "limits": {"import_kw": 50.0, "export_kw": 20.0}}. Measures and reports settled district import and export exceedances without curtailing or altering device dispatch. Either import_kw or export_kw may be omitted or None (unmonitored in that direction), or set to a non-negative scalar or dataset-step-0 anchored sequence in [kW]. Defaults to the schema value, else disabled.

    • evaluation_window (Union[bool, Mapping[str, Any]], optional) – Opt-in recurring local evaluation window for evaluate_v2() and KPI exports. Disabled by default. Pass True or {'enabled': True} to use the 16:00:00 to 19:00:00 starter window in the scenario’s local time, or pass {'enabled': True, 'start': 'HH:MM', 'end': 'HH:MM', 'timezone': ...} to override the bounds (including sub-hour boundaries and midnight wrap when start > end). Overrides evaluation_window in the schema.

    • **kwargs (dict) – Only the options listed above are accepted; any other keyword argument raises a TypeError that suggests the closest valid name.

    Notes

    Parameters passed to citylearn.citylearn.CityLearnEnv.__init__ that are also defined in schema will override their schema definition.

Defaults to EvaluationCondition.WITHOUT_STORAGE_BUT_WITH_PV, or WITHOUT_STORAGE_AND_PARTIAL_LOAD_BUT_WITH_PV for buildings with LSTM thermal dynamics: the same buildings without storage, PV retained.

    • comfort_band (float, optional) – Comfort band in degrees Celsius around the set point used by the thermal comfort KPIs. Defaults to each building’s comfort_band series.

    • include_business_as_usual (bool, default: True) – Also run, or reuse, the native business-as-usual rollout (citylearn.agents.baseline.BusinessAsUsualAgent on the same scenario and window) and add the *_business_as_usual_* values, deltas and ratios. The reference is rebuilt from the schema and the constructor arguments; a ValueError names the setting when it differs from this environment as captured at its last reset(). See the baselines guide for the settings that are compared.

    • include_battery_health_audit (bool, default: False) – Opt-in flag to append EV battery terminal state-of-health (SOH), capacity fade (kWh and ratio), and equivalent full cycles. Defaults to False so default KPI tables remain unchanged.

    • progress_callback (callable, optional) – Keyword-only. Receives scalar stage events while the table is computed. A callback that raises is logged and disabled; the table is unaffected, and no events or timings are added to it.

    Returns:

    One row per KPI and scope, with the columns:

    • cost_function (str): the KPI name, level_family_subfamily_metric_variant_unit. The last part is the unit, e.g. kwh, kw, eur, kgco2, hours or ratio.

    • value (float): the value; NaN when the KPI is undefined for this run, for example a service ratio without any event to serve.

    • name (str): the building name for building rows, 'District' for district rows.

    • level (str): 'building' or 'district'.

    • unit (str) and description (str): the unit and English description from the KPI catalogue.

    Which KPIs appear depends on the scenario’s assets and services. scorecard() selects the default subset. The KPI catalogue lists every name and the KPI reference guide defines every family. citylearn.multi_community.MultiCommunityEnv.evaluate_v2() returns these rows for each community, with a community_id column, plus 'portfolio' rows aggregated from the district rows.
