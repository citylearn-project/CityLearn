======================
Command Line Interface
======================

The listing commands and the default business-as-usual agent need only
CityLearn. Stable Baselines3 agents also need ``stable-baselines3>=2.4``, and
the bundled ``SAC`` and ``MARLISA`` agents the ``rl`` extra. See
:doc:`guides/running_simulations` for runnable commands, including a Stable
Baselines3 example, the evaluation window and the output files.
